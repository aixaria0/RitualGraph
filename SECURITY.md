# Security Policy

RitualGraph is a defensive security and assurance project.

## Reporting

Do not publish suspected vulnerabilities in the issue tracker when they could expose a real deployment. Report them privately to the repository owner first.

## Scope discipline

Reference threat models are simulations, not claims about named organizations or deployed systems. Research hypotheses must remain typed as hypotheses until reproducible evidence supports promotion.

The project does not accept changes that silently remove evidence status, weaken invariant checks, or execute arbitrary expressions from untrusted threat-model files.
